Site de Apostas
Este projeto é uma plataforma de apostas online onde os usuários podem participar de eventos, fazer apostas e tentar ganhar prêmios. O sistema permite criar eventos de apostas, com categorias específicas e valores de participação definidos. A plataforma também possui uma funcionalidade de carteira (wallet), onde os usuários podem depositar, sacar e consultar seus saldos.

Funcionalidades
Cadastro de Usuários: Os usuários podem se registrar com um nome de usuário, e-mail, senha e data de nascimento.
Login: Após o registro, os usuários podem fazer login para acessar sua conta e participar de apostas.
Criação de Eventos: Os usuários podem criar novos eventos de apostas, definir os valores de participação e o período de recebimento das apostas.
Apostas: Usuários podem apostar em eventos, com valores de participação personalizados.
Wallet (Carteira): A plataforma permite que os usuários realizem depósitos e saques, além de visualizar seu saldo atual.
Saque com Taxa: A funcionalidade de saque aplica uma taxa variável dependendo do valor do saque.
Histórico de Apostas: Os usuários podem consultar o histórico de suas apostas e transações financeiras.
Tecnologias Utilizadas
Backend: Python, Flask
Banco de Dados: MySQL
Frontend: HTML, CSS (com Bootstrap)
Controle de versão: Git
